# Pencatatan Produk - Michael Sin

**Catatan:** Proyek ini adalah milik Michael Sin. Kode sumber ini diunggah melalui akun GitHub Ahmad Faiq Zidane karena Michael sedang mengalami kendala teknis (error) saat membuka GitHub melalui Google Chrome dan browser lainnya.

## Deskripsi
Aplikasi desktop untuk mengelola pencatatan produk, dikembangkan menggunakan Java.

## Cara Menjalankan Aplikasi

Karena konfigurasi project dan struktur *build* sudah diatur sebelumnya, Anda dapat langsung menjalankan aplikasi ini dengan langkah berikut:

1. Buka aplikasi **Apache NetBeans** (atau IDE pilihan Anda yang mendukung Java).
2. Buka project melalui menu `File` -> `Open Project...` dan arahkan ke folder project.
3. Lakukan **Clean and Build** pada project untuk memastikan seluruh file dan *dependencies* terkompilasi dengan baik.
4. Jalankan aplikasi menggunakan tombol **Run** atau tekan shortcut **`Shift + F6`** pada keyboard Anda.
